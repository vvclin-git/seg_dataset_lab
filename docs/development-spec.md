# seg_dataset_lab 開發規格書

## 1. 產品目標與開發順序

`seg_dataset_lab` 是本機的語意分割資料集分析與檢視工具。首版驗收重點是從「哪個場景的小船特別多」點到單一目標，確認原圖、GT 輪廓及模型輸入尺度上的像素尺寸。通用資料層可用於其他語意分割資料集，初始操作流程以海事小目標為例。

| 階段 | 交付範圍 |
|---|---|
| 第一階段 | 資料夾匯入、GT JSON 配對、Regex 分組、選用 split 索引、目標尺寸分析、影像與 GT 檢視、HTML／CSV 報表。 |
| 第二階段 A | 選取既有目標，做原位亮度、色彩及對比調整，檢查 RGB 邊緣與原始 GT。 |
| 第二階段 B | 選取來源目標與背景，做跨影像 Copy-Paste，覆核合成 RGB 與 GT，按需匯出核准案例。 |

## 2. 第一階段需求

### 2.1 資料夾與 GT JSON

- 選取資料集根目錄後遞迴掃描影像，再選取對應的 GT JSON。影像以資料集內的相對路徑識別，同一檔名可出現在不同子目錄。
- 第一個 GT 支援格式採 COCO JSON。透過 `images.file_name` 配對影像，以 `image_id` 取得標註。優先使用相對路徑，僅在檔名唯一時允許用 basename 配對。支援 polygon 與 RLE 輪廓，並保留來源的影像 ID 和標註 ID。
- bbox-only 標註仍可瀏覽與統計 bbox 尺寸，輪廓面積顯示缺值，該筆不提供輪廓預覽或擴增。缺少 GT、標註格式無效、尺寸不一致或配對不唯一時，保留影像並列出問題。
- 對完整標註清冊，已登錄影像可以沒有目標類別的標註。對僅列出部分影像的清冊，未登錄影像維持「缺 GT」。報表分別顯示含目標、已標註但無目標及缺 GT 的影像數。
- 目標類別由使用者選擇，顯示 GT 內的 ID 與名稱。海事資料可選 Boat，另可指定 Sky、Water、Own Boat、Ignore 供後續擴增檢核。所有類別 ID 依資料集設定。

### 2.2 Regex 分組與 split 索引

- Regex 可以套用到檔名或以 `/` 分隔的資料集相對路徑。多條規則按使用者指定的順序比對，採用第一條命中，預覽同時列出未命中、多重命中、每組張數及代表檔名。
- 支援 Python 命名群組，例如 `scene`、`camera`、`run`、`segment`、`frame`。使用者可選分組欄位，`frame` 依數值排序。規則與分組設定存入專案 JSON。
- Split 由獨立的 `train.txt`、`val.txt`、`test.txt` 定義，每行一張影像。優先配對相對路徑，只有唯一檔名才允許退回 basename 配對。列出找不到、同名歧義及跨 split 衝突，衝突影像須解決後才視為已分配。
- 可省略 split 索引。此時仍分析資料夾內全部影像，split 顯示「未分配」。稍後匯入索引即可補上分配。Regex 提供場景與片段資訊，split 歸屬由索引決定。
- 能辨識同一片段的資料可顯示相鄰影格與跨 split 提示。相鄰關係用於人工檢查與抽樣，影格差距門檻由使用者指定。

### 2.3 尺寸分析與檢視器

- 保存原圖座標與所選工作網格。海事預設為 **960×768 直接縮放**。匯入尺寸、工作尺寸、座標換算方式一併列入報表。若實際模型前處理有裁切或補邊，須另確認座標映射再把數值解讀為模型輸入尺寸。
- 顯示 bbox 寬、高、對角線與有效 mask 面積。對角線以工作網格上的寬高計算，mask 以最近鄰方式轉入工作網格後計算像素數。若極小 mask 在縮放後消失，顯示提示並保留原尺度標註供檢查。
- 預設對角線分箱為 `<8`、`8–<16`、`16–<32`、`≥32 px`，可額外篩出 `8–<16 px 且高度 <4 px`。同時顯示物件數、含該組物件的影像數，以及各自的分母。整體影像數按唯一影像計算。
- 基本操作為「選分組或分箱 → 選影像 → 選目標」。畫布支援原圖、bbox、GT 輪廓／疊圖切換、縮放、平移和逐像素檢視。目標列表顯示場景、相機、航次／片段、frame 和 split。
- 技術選型採 Python、Tkinter／ttk、Pillow 與 OpenCV，Windows 本機執行，使用 uv 管理環境。掃描與縮圖解碼在背景執行，畫面更新由 Tk 主執行緒處理。影像及縮圖按需載入，僅在記憶體保留有限快取。

### 2.4 報表與保存

- HTML 報表包含資料概況、各場景的尺寸分布及資料配對問題。可選擇匯出 CSV，提供每個目標的影像相對路徑、來源標註 ID、分組、split、座標尺度與尺寸，以及分組統計明細。
- 報表中的目標 ID 可在檢視器查回原圖。專案 JSON 保存格式版本、資料路徑、GT 與 split 設定、Regex、工作網格及使用者設定。
- 預設只寫專案設定及使用者要求的統計報表。原始影像與標註以唯讀方式開啟，縮圖與預覽在記憶體產生。

## 3. 第二階段擴增需求

### 3.1 原位外觀調整

- 從同一張影像選一個有輪廓的目標，調整亮度、飽和度、冷暖色偏、目標內部對比，以及目標相對局部背景的亮度差。背景參考可選水面或天空，背景取樣不足時顯示提示。
- 預設依原輪廓調整，可選輪廓內側柔化。柔化權重混合原始 RGB 與調整後的 RGB，輪廓外權重為零。GT 類別及輪廓沿用原始標註。極薄目標預設使用原輪廓，並支援在工作網格上放大檢查是否出現硬邊或殘色。
- 提供同位置的原圖／調整後／GT 疊圖對照、即時預覽及一鍵重設。可保留多個外觀版本作覆核。

### 3.2 跨影像 Copy-Paste

- 從已配對且有有效輪廓的來源資料選一個目標，再選一張具可用 GT 的背景。每次試貼一個物件，第一版維持工作網格上的原尺寸。以船底作為拖放錨點，支援方向鍵逐像素微調。
- 顯示水面、天空與候選地平線供人工判斷位置。可跨水面及天空，出界或與受保護類別重疊須阻擋核准。海事預設保護既有 Boat、Own Boat、Ignore 與其他已標註目標。
- 新增物件的離散遮罩與船舶 RGB 使用同一幾何映射。GT 只在新增遮罩內更新目標類別。RGB 邊緣柔化與 GT 更新各自使用連續權重和離散類別。
- 保留待覆核、核准、退回及原因。每筆記錄案例 ID、來源影像相對路徑、標註 ID、背景影像相對路徑、錨點位置、工作網格、外觀設定與覆核狀態。HTML／CSV 增加案例明細與來源場景到背景場景的次數統計。
- 可在缺少 split 索引時互動試驗。訓練資料匯出時，僅納入已核准且所用影像全部屬於 Train 的案例。補匯入或更新索引後重新檢查資格。
- 專案 JSON 儲存試驗參數。重新開啟時從原始資料重建預覽。使用者可明確要求匯出選定案例的對照圖，或匯出合成 RGB、離散 GT 與配對清單。

## 4. 驗收案例

| 階段 | 操作 | 預期結果 |
|---|---|---|
| 一 | 開啟含同名檔、缺 GT 和 bbox-only 標註的資料夾 | 歧義列入問題清單。缺 GT 與已標註但無目標分開計數。bbox-only 可統計尺寸。 |
| 一 | 未提供 split，之後匯入含衝突的 TXT | 匯入前可以瀏覽全資料夾。匯入後更新 split 統計並列出衝突，不將衝突影像納入已分配樣本。 |
| 一 | 套用兩條可能重疊的 Regex | 預覽列出兩條命中及採用規則。確認後可按分組與數值 frame 排序。 |
| 一 | 篩選對角線 `8–<16 px` 且高度 `<4 px` | 能從清單打開該目標的原圖與 GT。相同篩選條件下，介面與報表的物件數、影像數一致。 |
| 一 | 關閉並重新開啟專案 | 恢復資料路徑、分組、split 和工作網格。瀏覽過程沒有新增影像副本。 |
| 二 A | 對極薄船身調整亮度與柔化，儲存後重開 | 可以重建調整前後的預覽，原始 GT 和輪廓外 RGB 保持一致。 |
| 二 B | 試貼到有效水面，再拖到受保護目標或畫面外 | 合法位置可核准，GT 變動僅在新增輪廓內。受保護區域與出界案例無法核准。 |
| 二 B | 補上 split 後匯出核准案例 | 只有來源及背景皆屬於 Train 的案例輸出 RGB、GT 和配對清單。 |
